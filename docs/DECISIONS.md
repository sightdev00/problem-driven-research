# 架构决定与待验证事项

## 已确定

- 核心对象为持续演化的研究；不存在通用或完全自动化的研究工具。
- 领域从问题入口指定，当前内置协议为视觉智能与物理理论。
- 人工必查来源与自动发现并用；模型进行受限多视角资料合议。
- 与目标关联程度决定子问题优先级，区分力和成本用于同级排序。
- 一轮研究允许模型提出下一步，执行须检查边界和预算。
- 模型分析精简后连同来源、适用范围和未知进入研究记录。
- 实验交付模块化的可执行脚本，依托工程仓库提供的能力说明；人提供真实素材。
- 抽象机制结论、具体工程结论分开；当前结论、研究历史、结论修订分开呈现。
- 判断修改保留历史；研究正文只保留影响判断的事项。
- 私有工程数据与可公开研究仓库分离。

## 尚待验证或确定

- 用首个真实主题确认领域协议的必要字段及是否覆盖关键机制。
- 对接用户服务器上的 Qwen3.8 27B 的实际地址、认证方式、模型名、输入能力；不得写入公开仓库。
- 检索接口的实际使用额度、授权条件及论文之外的官方来源读取方式。
- 工程仓库能力说明能否支撑可运行脚本；用真实仓库验证命令、数据格式及结果读取。
- 模型多视角调用的实际收益与成本；无收益则合并为一次分析。
- 当前结论视图的自动生成与人工编辑怎样保持单一记录源。

## 阶段边界

本包只冻结当前架构讨论内容。模块目录、文件格式和状态名称是拟议方案，后续代码实施可依据真实主题验证调整，不应被当作已实现接口。
